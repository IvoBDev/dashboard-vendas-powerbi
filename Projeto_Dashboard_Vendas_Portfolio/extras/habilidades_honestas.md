# Descrição honesta das habilidades

Use como base para o currículo, o LinkedIn e entrevistas. A ideia é descrever o que você fez de fato, sem inflar o nível.

## O que este projeto comprova

- **Modelagem dimensional:** montar um esquema em estrela, criar relacionamentos 1:*, marcar tabela de datas e ordenar o mês.
- **DAX (nível inicial a intermediário):** CALCULATE, SUM, DISTINCTCOUNT, DIVIDE, variáveis (VAR), ISFILTERED, HASONEVALUE e SAMEPERIODLASTYEAR. Medidas em camadas (receita, custo, lucro, margem).
- **Power Query (básico):** importar CSV e Excel, ajustar tipos de dados e conferir valores.
- **Visualização e UX:** hierarquia de KPIs, escolha de gráficos, tema próprio, menu retrátil com bookmarks e Painel de Seleção, filtros sincronizados, popup informativo.
- **Validação:** conferir cada medida contra um cálculo independente, testar filtros combinados e encontrar um erro de lógica no material inicial.
- **Documentação:** dicionário de dados, premissas, limitações e README.

## O que este projeto NÃO comprova (ainda)

- Conexão com bancos de dados, atualização agendada ou publicação no Power BI Service.
- DAX avançado (iteradores complexos, tabelas calculadas, RLS).
- Trabalho com dados reais e sujos, ou com grandes volumes.
- Experiência em um contexto de negócio real.

## Como falar em entrevista

> "Construí um dashboard de vendas em Power BI com dados fictícios, com modelo em estrela e medidas DAX que validei contra cálculos independentes. Fiz o projeto com a ajuda de uma IA como mentor: ela me explicava e eu montava e conferia cada etapa. Ainda não trabalhei com dados reais, mas sei explicar cada decisão do modelo e cada medida."
